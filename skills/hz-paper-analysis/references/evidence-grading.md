# 生信论文证据分级与措辞规则

## 1. 证据类型

这些类型不是简单的“低到高”排行榜，而是说明主张由什么证据支持。最终强度取决于样本、对照、重复、统计单位和验证是否匹配。

| 类型 | 可以支持 | 不能单独支持 |
|---|---|---|
| 描述性证据 | 某细胞/基因/空间信号存在、富集或共同变化 | 机制、方向性、因果 |
| 组间关联 | A 与 B 在样本中相关、某状态与结局相关 | A 导致 B |
| 计算推断 | 候选细胞状态、配体-受体、靶基因、空间丰度或轨迹 | 真实细胞接触、蛋白结合、信号激活、谱系迁移 |
| 体外/离体扰动 | 在特定细胞系、培养体系或组织模型中改变表型 | 患者体内机制、跨模型普适性 |
| 临床关联/预测 | 标志物与分型、预后或风险有统计关联，模型有一定区分能力 | 已可用于临床诊断、治疗或决策 |
| 因果机制证据 | 合适来源特异性干预、救援/阻断、对照和体内重复共同支持因果链 | 超出模型、组织或队列范围的普遍机制 |

## 2. 常见方法的解释边界

| 方法 | 正确表述 | 避免表述 |
|---|---|---|
| UMAP/t-SNE | 在表达空间中可视化状态分布 | 证明细胞存在真实离散生物学状态 |
| marker 注释 | 根据标志基因给出细胞类型候选注释 | 仅凭少数 marker 证明细胞来源 |
| Ro/e、丰度比例 | 描述组成相对富集或偏移 | 证明细胞迁移或扩增机制 |
| Monocle/伪时序 | 给出转录状态排序或连续变化 | 证明真实谱系、时间顺序或迁移方向 |
| CellChat/CellPhoneDB | 根据表达和先验库提出通讯候选 | 证明配体分泌、受体激活或信息流方向 |
| NicheNet | 提出配体与下游靶程序的候选联系 | 证明配体直接造成靶基因变化 |
| cell2location/RCTD | 推断 spot/区域中的细胞丰度 | 把推断丰度写成真实单细胞位置 |
| SpaGene/空间相关 | 描述空间邻域中的协同变化 | 证明细胞直接接触或信号传递 |
| mIF/IHC | 支持标志物在组织中的表达和邻近 | 证明细胞来源、分泌方向或功能 |
| 相关/回归 | 量化变量共同变化及调整后的关联 | 证明因果关系 |
| Kaplan-Meier/Cox | 评估结局分层或协变量关联 | 证明标志物能改善临床决策 |
| ROC/timeROC | 描述区分或预测性能 | 未经独立验证就称为临床可用 |
| siRNA/CRISPR 敲低 | 在模型中提供基因依赖或功能证据 | 没有救援/阻断时宣称作用专一 |
| 条件培养基 | 提示分泌环境影响受体细胞表型 | 证明某一个分泌因子是唯一原因 |
| GWAS/MR | 提供遗传关联或工具变量支持 | 直接替代药效、安全性或体内实验 |

## 3. 样本层级检查

写任何 `n` 前，明确它属于哪一层：

```text
患者/供体
  > 组织块/样本
  > 切片
  > ROI/spot
  > 细胞
```

- 视野、spot、ROI 和细胞通常不是独立患者重复；
- 空间置换次数增加的是随机化精度，不是患者样本量；
- 一张切片不等于一名患者，多个切片也不自动等于多个独立样本；
- 细胞系实验不能直接替代患者组织或体内模型；
- 跨器官、跨癌种或跨平台数据应标记为外部支持，不能写成同病种独立验证。

## 4. 来源特异性检查

当同一配体或信号分子在多个细胞群中表达时，按以下顺序检查：

1. 是否有细胞类型特异的表达和空间证据；
2. 是否有来源特异的敲低、敲除、阻断或救援；
3. 是否在独立样本或体内模型中重复；
4. 若没有，使用“某细胞群是候选来源之一”，不要写成“由该细胞分泌并驱动”。

## 5. 推荐措辞

### 可直接使用

- “结果显示……”
- “该信号与……共同变化”
- “计算分析提示……”
- “空间共定位支持……的组织邻近”
- “体外扰动在该模型中支持……功能”
- “在该队列中与……相关”
- “可作为待验证的候选机制/标志物”

### 需要补足证据后才能使用

- “证明……”
- “驱动……”
- “导致……”
- “直接激活……”
- “决定……”
- “临床可用……”

## 6. 最低复核清单

- [ ] 主张能回到具体 Figure、表格或实验；
- [ ] 计算推断和实验验证分开写；
- [ ] 相关性没有被改写成因果；
- [ ] 患者/切片/spot/细胞统计单位没有混淆；
- [ ] 外部验证的疾病、器官、平台和样本结构已写清；
- [ ] 内部阈值选择、同队列评估和缺少独立验证已标记；
- [ ] 结论强度与证据等级一致。
